# EL RICO SAZÓN — Identidad visual

Logotipo para restaurante. El concepto reúne la **llama del sazón** y los **cubiertos cruzados** dentro de un sello circular dorado: cocina, fuego y sabor.

## Archivos

| Archivo | Uso |
|---|---|
| `logo.svg` | Logotipo principal, vectorial y con fondo transparente. Es el archivo maestro. |
| `logo-1600.png` | Versión PNG a 1600 × 1600 px con transparencia. |
| `logo-800.png` | Versión PNG a 800 × 800 px con transparencia. |
| `logo-horizontal.svg` | Versión horizontal para fondos oscuros (letreros, redes, empaques). |
| `logo-horizontal-claro.svg` | Versión horizontal para fondos claros (menús, papelería, facturas). |
| `favicon.svg` | Icono compacto para la pestaña del navegador. |
| `presentacion.html` | Lámina de presentación editable en el navegador. |
| `presentacion.png` | La misma lámina exportada como imagen. |

## Paleta

- **Espresso** `#1B100A`
- **Oro sazón** `#D9AE56`
- **Brasa** `#E8461F`
- **Crema** `#F7EFE2`
- **Nogal** `#6B3F22`

## Tipografía

Georgia (serif) en sus variantes bold. Es una fuente presente en la mayoría de los sistemas; si se necesita una versión web, puede sustituirse por *Playfair Display*.

## Recomendaciones de uso

- Deja un margen libre alrededor del sello equivalente a un 15 % de su diámetro.
- Tamaño mínimo recomendado para el sello completo: **120 px** en pantalla o **3 cm** impreso.
- No deformes, rotes ni cambies los colores del logotipo.
- Sobre fondos claros usa la versión horizontal clara; sobre fondos oscuros, la versión dorada.
- Para fondos con mucha textura o fotografías, coloca el sello sobre un área limpia.

## Edición

Los archivos `.svg` se pueden abrir y editar en Illustrator, Inkscape, Affinity Designer o Figma. Los textos están como texto vivo (no convertidos a curvas), así que puedes ajustar el nombre o el eslogan si lo necesitas.
